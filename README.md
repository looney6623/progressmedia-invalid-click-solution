# 프로그레스미디어 무효클릭차단 솔루션

Next.js, React, TailwindCSS, Recharts 기반 관리자 대시보드 데모입니다. 현재 버전은 서버 없이 `lib/clickData.js`의 더미 클릭 로그와 자동 판정 로직으로 동작합니다.

## 실행

```bash
npm install
npm run dev
```

## 포함 화면

- 메인 대시보드
- 실시간 클릭 로그
- 무효클릭 분석
- 차단 관리
- 광고주 리포트

## 판정 로직

- 동일 광고주, 캠페인, IP 기준 10분 내 3회 클릭 시 의심 처리
- 동일 광고주, 캠페인, IP 기준 10분 내 5회 클릭 시 차단 처리
- 체류시간 3초 이하이면 위험도 증가
- 페이지 이동 0회이면 위험도 증가
