# BLOCKING POLICY

무효클릭 판정 및 차단 정책 초안입니다. 실제 집행 전 광고주별 업종, 트래픽 규모, 매체 정책에 따라 보정이 필요합니다.

## 기본 판정 기준

| 조건 | 판정 | 설명 |
| --- | --- | --- |
| 10분 내 3회 클릭 | 의심 | 동일 광고주, 캠페인, IP hash 기준 |
| 10분 내 5회 클릭 | 차단 | 반복 클릭 가능성이 높음 |
| 1시간 내 8회 클릭 | 차단 | 긴 시간 창에서 반복 유입 감지 |
| 체류시간 3초 이하 | 위험도 가중 | 랜딩 내용 소비 없이 이탈 |
| 페이지 이동 0회 | 위험도 가중 | 추가 탐색 없는 저품질 세션 |

## 위험도 점수 예시

- 기본 정상 클릭: 18점
- 10분 내 3회 이상: 64점
- 10분 내 5회 이상: 90점
- 1시간 내 8회 이상: 92점
- 체류시간 3초 이하: +12점
- 페이지 이동 0회: +10점
- 88점 이상: 차단
- 58점 이상: 의심

## 수동 차단과 자동 차단

### 자동 차단

- 시스템 규칙으로 등록됩니다.
- 기준 클릭 로그와 판정 사유를 반드시 보관합니다.
- 해제 시 관리자 승인 또는 만료일 도래가 필요합니다.

### 수동 차단

- 관리자가 IP 또는 IP hash 기준으로 등록합니다.
- 차단 사유 입력을 필수로 합니다.
- 등록자, 등록일, 해제자를 기록합니다.

## 차단 기간 정책

권장 기본값:

- 의심 관찰: 24시간
- 자동 차단: 7일
- 반복 자동 차단: 30일
- 수동 차단: 관리자 선택, 기본 30일
- 악성 패턴 확정: 90일 또는 영구 차단 검토

만료 시:

- 자동 해제하되 동일 패턴 재발 시 기간을 연장합니다.
- 해제 후 24시간은 재발 여부를 관찰합니다.

## 오탐 해제 정책

- 광고주 또는 운영자가 오탐을 신고할 수 있어야 합니다.
- 해제 전 확인 항목:
  - 동일 IP의 실제 전환 또는 상담 여부
  - 체류시간과 페이지 이동이 정상인지
  - 사내망, 대리점, 병원/매장 공용망인지
  - 특정 캠페인 테스트 트래픽인지
- 해제 시 해당 IP는 일시 허용 목록에 넣을 수 있습니다.
- 오탐 케이스는 detection rule 보정 데이터로 남깁니다.

## 광고 플랫폼 과금 차단과 사이트 접근 차단의 차이

### 광고 플랫폼 과금 차단

- 네이버/구글/메타 등 광고 플랫폼의 과금 자체를 직접 차단하는 의미가 아닙니다.
- 본 시스템은 의심 클릭을 탐지하고 리포트화하여 광고 운영 판단을 돕습니다.
- 플랫폼의 무효클릭 환급/제외 정책은 각 플랫폼 기준을 따릅니다.

### 사이트 접근 차단

- 광고주 사이트 또는 랜딩 페이지에서 특정 IP/세션 접근을 제한하는 조치입니다.
- 실제 사이트 접근 차단은 광고주 서버, WAF, CDN, edge function 등과 연동해야 합니다.
- 본 프론트 데모의 차단은 UI 상태 표시이며 실제 접근 차단은 수행하지 않습니다.
