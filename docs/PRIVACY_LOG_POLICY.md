# PRIVACY AND LOG POLICY

개인정보 및 로그 처리 정책 초안입니다. 실제 서비스 전 법무 검토와 개인정보처리방침 반영이 필요합니다.

## IP 처리 원칙

- IP 원문 저장은 금지하거나 강하게 제한합니다.
- 운영 화면에는 masked IP만 표시합니다.
- 분석과 반복 클릭 판정은 `ip_hash` 기준으로 수행합니다.
- hash에는 서버 비밀 salt를 사용하고 salt는 외부에 노출하지 않습니다.
- 장애 분석 등 원문 IP가 꼭 필요한 경우 별도 권한과 짧은 보관 기간을 둡니다.

## IP hash 및 masking 예시

- 원문: `211.44.18.91`
- masking: `211.44.*.91`
- hash: `sha256(server_salt + ip)`

## cookie/localStorage 사용 고지

추적 스크립트는 방문자/세션 구분을 위해 first-party cookie 또는 localStorage를 사용할 수 있습니다.

고지 필요 항목:

- 수집 목적: 광고 무효클릭 탐지, 광고 성과 분석
- 저장 항목: 임의 방문자 ID, 세션 ID, 페이지뷰, 체류시간
- 보관 기간: 예: 90일 또는 180일
- 거부 방법: 브라우저 저장소 삭제 또는 쿠키 차단

## 로그 보관 기간

예시 정책:

- 원천 클릭 로그: 90일
- 집계 리포트: 180일
- 차단 이력: 180일
- 보안 감사 로그: 1년
- 삭제 요청 또는 계약 종료 시 광고주별 데이터 삭제

## 광고주별 데이터 분리

- 모든 주요 테이블은 `advertiser_id`를 포함합니다.
- 관리자 조회는 광고주 권한 범위로 제한합니다.
- 멀티테넌트 환경에서는 row-level security 또는 서비스 레이어 권한 검증을 적용합니다.

## 관리자 권한 제한

권장 권한:

- viewer: 리포트 조회
- operator: 로그 조회, CSV 내보내기
- manager: 차단 등록/해제
- admin: 광고주 등록, 규칙 변경, 권한 관리

민감 기능:

- IP hash 조회
- CSV 내보내기
- 차단 해제
- 데이터 삭제

위 기능은 감사 로그를 남깁니다.

## 삭제 요청 대응

- 광고주 또는 이용자 삭제 요청 접수 경로를 마련합니다.
- visitor_id, session_id, ip_hash 등으로 관련 데이터를 조회합니다.
- 삭제 또는 비식별화 처리 후 처리 결과를 기록합니다.
- 법적 보관 의무가 있는 로그는 별도 보관 근거와 만료일을 관리합니다.

아래 문구는 예시이며 실제 적용 전 법무 검토가 필요합니다.
